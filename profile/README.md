# NexaCloud

**Web hosting and domains.** Push to GitHub, go live with HTTPS on your own domain.

[Website](https://nexaclouds.online) · [Docs](https://nexaclouds.online/docs/) · [Guides](https://nexaclouds.online/guides/) · [Pricing](https://nexaclouds.online/pricing/) · [Domains](https://nexaclouds.online/domains/) · [Português](https://nexaclouds.online/pt/)

## What NexaCloud does

- **Static sites** (Vite, React, Vue, Astro, Hugo, Docusaurus, Next.js export) served from Cloudflare's global network.
- **Server apps**: Next.js with SSR, Node, Python and any Dockerfile, run as containers with logs, env variables, cron jobs and background workers.
- **Every push deploys**, every pull request gets a preview URL, and every version can be rolled back in one click.
- **Free HTTPS address** for each project at `name.nexaclouds.online`, plus custom domains with automatic HTTPS.
- **Domains**: buy .com, .com.br, .online, .click and more inside the dashboard, with DNS and WHOIS privacy, connected in one click.
- Builds run in **your own GitHub Actions**, so there are no build-minute bills.
